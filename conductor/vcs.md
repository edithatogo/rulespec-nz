# Git Workflow

- Work from a clean branch based on the fork's current `main`.
- Keep commits focused and use Conventional Commit messages.
- Do not rewrite shared history or modify the upstream repository.
- Push only when explicitly authorized, then open a pull request against the fork.
- Treat hosted checks, review, and merge as distinct gates.
- Do not associate a pull request with historical work when the disposition is explicitly no-PR.
